# Exercice 3 - RodiumAI avec le SDK JavaScript

Script interactif Node.js utilisant le SDK `rodiumai` pour le chat, l'image et la vidéo.

## Installation

Node.js 18 ou supérieur :

```bash
npm install
```

Copiez `.env.example` vers `.env` et renseignez votre clé. Définissez aussi `RODIUMAI_IMAGE_MODEL` et `RODIUMAI_VIDEO_MODEL` avec des identifiants disponibles dans votre catalogue.

## Lancement

```bash
npm start
```
